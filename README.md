# 📌 Videojuego Pacman en Java

Proyecto de un Videojuego de Pacman realizado en 1º de DAM.

## 🚀 Tecnologías Utilizadas

Para este trabajo he utilizado JAVA, para el desarrollo de la parte grafica he utilizado swing y awt, ademas he utilizado una BBDD MySql para guardar puntuaciones.

## ✨ Características Principales

*   Distintos comportamiento depedende del fastasma.
*   Distintas opciones durante la partida: pausar, reiniciar, ir al menu etc...
*   Distintos mapas.

## 🛠️ Instalación y Ejecución local

Sigue estos pasos para probar el proyecto en tu entorno local:

1. Clona el repositorio:
   ```bash
   git clone [https://github.com/pablo-navia5/PacmanJava](https://github.com/pablo-navia5/PacmanJava)
   ```
2. Abre el proyecto en tu IDE
3. Asegurate de tener la BBDD funcionando y ejecutar el script: `scriptBD.sql`
4. Ejecuta el proyecto
